Source of **[furkankoykiran.com.tr](https://furkankoykiran.com.tr/)**, the personal site of Furkan Köykıran: projects, open-source contributions, an about page and contact details. Turkish at the root, English under [`/en/`](https://furkankoykiran.com.tr/en/). The blog is a separate site at [blog.furkankoykiran.com.tr](https://blog.furkankoykiran.com.tr/).

## Stack

- [Hugo](https://gohugo.io/) extended 0.167.0, with the site's own templates and CSS. The [Blowfish](https://blowfish.page/) theme (Git submodule) provides the icon set and Markdown render hooks.
- A few kilobytes of vanilla JavaScript for progressive enhancements; every page works without it.
- Python 3.11+ scripts that keep the project and contribution data current.
- GitHub Actions and GitHub Pages for builds and hosting.

## Local development

```sh
git clone --recurse-submodules https://github.com/furkankoykiran/furkankoykiran.github.io.git
cd furkankoykiran.github.io
hugo server                 # http://localhost:1313/
hugo --minify --gc          # production build into public/
```

Use Hugo **extended 0.167.0** (the version CI uses). If you cloned without `--recurse-submodules`, run `git submodule update --init --recursive` first.

## Editing content

| What | Where |
|---|---|
| Home page copy and all interface text | `i18n/tr.yaml`, `i18n/en.yaml` (keys under `fk`) |
| About, contributions and privacy pages | `content/tr/*.md`, `content/en/*.md` (same file names; English URLs come from `url:` front matter and the permalinks in `config/_default/languages.en.toml`) |
| Projects | `data/projects.json`, generated by `scripts/build_projects.py`; one page per project is created by `content/*/projeler/_content.gotmpl` |
| Contributions | `data/contributions.json`, generated by `scripts/fetch_contributions.py` |
| Name, photo, e-mail, social links, blog feed | `config/_default/params.toml` |
| Menus | `config/_default/menus.tr.toml`, `menus.en.toml` |
| Styles and colours | `assets/css/custom.css`, `assets/css/schemes/fk.css` |

Content pages can use two shortcodes: `{{< email >}}` prints the e-mail link (stored base64-encoded and assembled in the browser) and `{{< socials >}}` the social links. Open Graph images are drawn at build time from `assets/img/og-base.png`; set `ogTitle` or `ogKicker` in front matter to change their text.

## Scripts

All scripts take `--help`, read their defaults from the repository (`config/_default/*.toml`), and log to stderr. They need Python 3.11+ and the standard library only, except where noted.

| Script | Purpose |
|---|---|
| `scripts/fetch_contributions.py` | Collects merged pull requests in repositories the author does not own and writes `data/contributions.json`. Uses the GitHub CLI (`gh`); set `GH_TOKEN` in CI. |
| `scripts/build_projects.py` | `--refresh-only` updates stars and dates in `data/projects.json` (what CI runs). `--audit FILE` or `--inventory FILE` rebuilds it from a repository audit. |
| `scripts/indexnow.py` | `snapshot`, `diff` and `submit` steps that report changed URLs to IndexNow after a deploy. |
| `scripts/check_reserved_paths.py` | Fails the build if `public/` would shadow a path used by another site on the domain (`projectSites` in `params.toml`). |
| `scripts/blocklist.py` | Manages `data/blocklist.toml`, a hashed list of names that must never be published; `check` scans files for them. |
| `scripts/make_og_base.py` | Renders the Open Graph background. Only needed when the photo or branding changes; requires Pillow (`pip install pillow`). |

The GitHub user defaults to `author.githubUser` in `params.toml` (override with `--user` or `PORTFOLIO_GITHUB_USER`). Lint with `ruff check scripts && ruff format --check scripts`; the configuration is in `pyproject.toml`.

## Deployment

`.github/workflows/deploy.yml` runs on every push to `main`, nightly and on demand. It refreshes the contribution and project data, builds with Hugo and deploys to GitHub Pages; afterwards it notifies IndexNow of changed URLs. `.github/workflows/lighthouse.yml` runs Lighthouse CI on pull requests against the budgets in `.lighthouserc.json`. Dependabot keeps the theme submodule and the actions up to date.

One-time setup on a new repository: under *Settings → Pages*, set **Source** to **GitHub Actions** and enter `furkankoykiran.com.tr` as the custom domain. `static/CNAME` documents the domain, but a Pages site deployed by Actions takes it from the settings.

Analytics and search-engine verification IDs are optional and are not committed. Set them as repository variables (*Settings → Secrets and variables → Actions → Variables*); the deploy workflow passes them to Hugo as `HUGO_PARAMS_*`:

| Variable | Used for |
|---|---|
| `GA4_ID` | Google Analytics 4 measurement ID |
| `CLARITY_ID` | Microsoft Clarity project ID |
| `CF_BEACON_PORTFOLIO` | Cloudflare Web Analytics token |
| `GOOGLE_SITE_VERIFICATION` | Google Search Console verification |
| `BING_SITE_VERIFICATION` | Bing Webmaster Tools verification |
| `YANDEX_VERIFICATION` | Yandex Webmaster verification |
| `INDEXNOW_KEY` | IndexNow key; `static/<key>.txt` must contain the same key |

The consent banner and analytics scripts are only rendered when at least one analytics ID is set. Other repositories publish sites under this domain (`/awesome-trending-repos/`, `/EarthquakeSim/` and others listed in `params.toml`); the build fails if this site would generate one of those paths.
